# TikoWikoBakery

Jeu mobile de gestion de boulangerie 3D créé par **tikowikoFamily**.

## Version 1.1 — refonte premium

- nouvel écran de lancement TikoWikoBakery ;
- nouvelle icône Android avec le croissant et le pain mascottes ;
- interface plus chaleureuse, moderne et lisible ;
- éclairage 3D amélioré ;
- poutres, lampes, coin café, table et ventilateur animé ;
- optimisation de la qualité graphique sur mobile ;
- génération automatique de l’APK par GitHub Actions.

Le workflow Android fabrique automatiquement l’APK de test à chaque mise à jour de la branche `main`.
